# Fire Expert Frontend

## Instalacja

```bash
npm install
```

## Uruchomienie

```bash
npm run dev
```

Aplikacja będzie dostępna pod adresem: http://localhost:3000

## Konfiguracja

Backend API powinien działać na porcie 8080. Proxy jest skonfigurowane automatycznie w `vite.config.ts`.

## Technologie

- React 18
- TypeScript
- Vite
- Axios

## Funkcje

- ✨ Elegancki interfejs w stylu ChatGPT
- 🔥 Animowane wyświetlanie odpowiedzi (streaming effect)
- 💬 Historia konwersacji
- 📱 Responsywny design
- ⌨️ Skróty klawiszowe (Enter - wyślij, Shift+Enter - nowa linia)
- 🎨 Ciemny motyw
